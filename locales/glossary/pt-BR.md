# Portuguese (pt-BR) glossary

Read this before changing `locales/pt-BR.json`.

## Voice and form

- Concise technical Brazilian Portuguese (`você`; buttons use infinitives: `Salvar`, `Testar conexão`, `Verificar novamente`).
- Keep engine/product names (`Culprit`, `SQL Server`, `PostgreSQL`, `TimescaleDB`, `YugabyteDB`, `MySQL`, `MariaDB`, `ClickHouse`, `SQLite`, `Azure SQL`, `ADX`), SQL keywords, wait types, system view names and plan operator names in English.
- Plural format (`plural: "pt"`): include `one` (`0` and `1` in Brazilian Portuguese CLDR) and `other` (plus `=0` when English has `=0`).
