# Russian (ru) glossary

Read this before changing `locales/ru.json`.

## Voice and form

- Formal technical Russian (`вы` lowercase; infinitives or imperatives as appropriate; buttons use concise nouns/infinitives: `Сохранить`, `Проверить подключение`, `Сканировать повторно`).
- Keep engine/product names (`Culprit`, `SQL Server`, `PostgreSQL`, `TimescaleDB`, `YugabyteDB`, `MySQL`, `MariaDB`, `ClickHouse`, `SQLite`, `Azure SQL`, `ADX`), SQL keywords, wait types, system view names and plan operator names in English.
- Plural format (`plural: "ru"`): include Russian CLDR cardinal forms `one`, `few`, `many`, and `other` (plus `=0` when English has `=0`).
