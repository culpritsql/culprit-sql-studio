# Portable Culprit parsers

This browser ES module calls the same pure Rust plan, comparison, deadlock and export owners as Culprit. It opens no database, workspace or credential profile. Its model declarations are generated by the existing Core `ts-rs` owner and packaged as a closed transitive declaration set; there is no second TypeScript model.

Build from the repository root after the affected Core/Plans tests have generated current bindings:

```sh
python3 dev/licenses.py
python3 dev/build-wasm.py --check-prerequisites
python3 dev/build-wasm.py
node dev/smoke-wasm.mjs
```

The build requires the `wasm32-unknown-unknown` target, the `wasm-bindgen` CLI matching the locked crate version, the existing app TypeScript installation, and `target/licenses/THIRD-PARTY-LICENSES.txt` generated by the existing license tool. That tool requires cargo-about and the installed app packages; the builder copies the same notices into `pkg/THIRD-PARTY-LICENSES.txt`. Pass `--bindgen /path/to/wasm-bindgen` to reuse a matching existing executable without changing PATH. It uses the existing Cargo target/cache and release profile. It does not install dependencies or require `wasm-pack` or a Wasm optimizer. `pkg/build-report.json` records raw, gzip and Brotli sizes, hashes and the declaration sources. Size is measured; this package does not promise a 200 KB binary.

For another local project, build this package first and point a `file:` dependency at this folder, such as `"@culpritsql/culprit-wasm": "file:../culprit/packages/culprit-wasm"`.

Serve the built package over HTTP with `.wasm` files served as `application/wasm`. Import its ESM entry and initialize the module before using its synchronous operations:

```ts
import { init, parsePlan, diffPlans, parseDeadlock, exportPlan } from "@culpritsql/culprit-wasm";

await init();
const before = parsePlan(beforeText);
const after = parsePlan(afterText, "postgres");
const difference = diffPlans(before, "before", after, "after");
const deadlocks = parseDeadlock(deadlockText);
const file = exportPlan(after, "query plan", "markdown", { redact: true, notes: [] });
```

Inputs are decoded text or exact Core model objects. An optional engine hint uses the shared strict native-format parser and rejects an incompatible engine. Comparison accepts optional explicit `CompareContext`; it never discovers a scan. Deadlock parsing returns Core `Deadlock[]`, preserving the parser’s original source and known/unknown clock semantics. Export keeps the shared redaction, HTML escaping and native-text refusal policy; the facade supplies a UTC-minute export footer from its own clock, never a native observation timestamp.

Parser/export failures throw `ParserError` with the original Core error in `.error` (`code`, `message`, `hint`, optional `detail`). Internal JSON marshalling uses serde’s existing `Result` representation; no domain DTO or parser is duplicated in JavaScript. The lower-level `*Json` exports are implementation details behind the typed package entry.

The default Wasm crate includes English only. Its optional `locales` Cargo feature forwards the shared catalog feature; the native application retains its existing language policy. Building this package does not migrate application components or change the desktop IPC contract.

The browser smoke loads the actual packaged module in Chromium over its own temporary loopback server. It exercises SQL Server, PostgreSQL JSON/text, MySQL JSON/tree, MariaDB, Yugabyte and SQLite fixtures, exact comparison, deadlock parsing, export privacy and typed error refusals. It closes its browser/server on success or failure and does not use the app’s dev server.

The package’s final Wasm link reserves a 32 MiB linear-memory stack, matching Core’s existing XML parsing/walking budget; it does not change global `RUSTFLAGS` or dependency compilation. This reserve is runtime memory, not a compressed-download size claim. The browser smoke must still establish that the VM call stack accepts the supported XML/plan depths. It checks a complete 1024-deep XML DOM, controlled over-depth/DTD/malformed refusals, 56/57 operator depths, native export privacy and continued use after refusals. Native source-text ceilings stay with the shared parser; model/context JSON arguments reuse its `MAX_PLAN_BYTES` ceiling before deserialization.
